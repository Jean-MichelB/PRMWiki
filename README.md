# PRM => Wiki documentation project
 
## Summary

This repository contains the manual for RiscOS. OS SWIs v3.40 (14 May 2021)
The manual has been modified for each file in it containing a link to the PRMs.
All files containing "<PRM" have on their last line.
The program program adds an additional line at the end of the file

 example:
See <PRM 1, page 319=>PRM-1:319>.
<Wiki OS_AddCallBack=>#url https://www.riscosopen.org/wiki/documentation/show/OS_AddCallBack> 

for information just for OS_ there are more than 300 files!

## History
I found it annoying to come across the "PRM" panel every time, when now they are at our disposal, with the DDE.
I discovered that they were also documented on wikidoc, I started adding links manually to test.
There has been a lot of work done on this site, and everyone can participate in its development.
